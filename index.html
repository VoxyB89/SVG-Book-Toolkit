    Setup

    1. Install Node.js.
    2. In this folder run npm install pdf-lib sharp then node server.js.
    3. Open this HTML file in Chrome or Edge. Keep the terminal running.

    Download a book

    1. Open Batch downloader.
    2. Paste an example page SVG URL. Check that the pattern has {n}.
    3. Set the page range. Leave “Download referenced images” on.
    4. If the site needs login: proxy = http://localhost:8788/proxy?url= and paste your Cookie header.
    5. Start → Download ZIP → unzip somewhere convenient.

    Make a PDF

    1. Open Folder → PDF.
    2. For a big book, paste the absolute path to the unzipped folder and use Convert via local server.
    3. When it finishes, open the combined.pdf sitting next to that folder (File Explorer).
    4. Small sets can use “Convert in browser” after choosing the folder.

    IDM / “Failed to fetch”

    Internet Download Manager sometimes intercepts PDF responses from localhost. The server writes the file to disk on purpose so that doesn’t matter. Open the path shown in the log.
